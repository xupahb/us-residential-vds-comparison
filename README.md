## 购买前最值得检查的 6 个参数

### 1. Static 还是 Dynamic

这是第一道筛选。

需要长期绑定固定出口环境时，应确认产品写的是“静态住宅 IP”而不是动态住宅、NAT 或普通原生 IP。

### 2. 流量还是不限

169 元的入门 VDS 是 3TB/月，299 元为 6TB/月，699 元为 20TB/月；399 元及以上部分方案则切换到不限流量。

不要只看 Mbps。

### 3. 真实需要多少带宽

100Mbps、200Mbps、300Mbps 的差距只有在实际业务产生足够并发或传输需求时才有意义。

### 4. IP 是否能满足你的业务

住宅 IP 不代表所有平台都接受。

尤其是电商、社交媒体、金融和流媒体服务，不同平台的地区政策和风险控制方式并不一样。购买前应该先确认目标平台本身允许你的使用方式。

### 5. 退款规则

普通美国住宅 VPS 当前不少页面写有 48 小时不满意退款，而美国静态住宅 VDS 页面明确属于特殊产品，退款只退网站余额。

这两个政策不要混为一谈。

### 6. 大陆访问路径

如果你人在中国大陆操作，看到“美国住宅 IP”之后不要停止比较。当前静态住宅 VDS 页面明确提示非大陆直连优化网络；如果你的业务大量访问发生在中国大陆侧，就应该把线路路径一并纳入考虑。
